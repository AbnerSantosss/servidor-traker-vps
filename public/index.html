Como funciona

Três passos, um webhook.

Você não instala SDK nem depende do navegador manter a aba aberta. É uma chamada HTTP.

01

Cadastre o site

No painel, crie o projeto e receba a URL de webhook exclusiva dele.

02

Dispare o evento

Seu backend manda um POST para essa URL dizendo qual evento aconteceu — no formato que ele já usa hoje.

03

O servidor reencaminha

Ele hasheia os dados sensíveis e envia a conversão para o Meta e o Google por você.

Os eventos

Seis eventos cobrem o funil inteiro.

O campo event_name no webhook diz qual é. Cada um já tem o mapeamento sugerido para Meta e Google.

page_view

Pageview

Uma página foi vista. Topo do funil, base para remarketing.

Meta · PageViewGA4 · page_view
sign_up

Cadastro

O visitante criou conta ou deixou os dados. Um lead entrou.

Meta · CompleteRegistrationGA4 · sign_up
begin_checkout

Início de checkout

Começou a finalizar a compra. Sinal forte de intenção.

Meta · InitiateCheckoutGA4 · begin_checkout
pix_gerado

PIX gerado

O comprador pediu o código para pagar. Intenção forte — mas ainda não é receita.

Meta · AddPaymentInfoGA4 · add_payment_info
abandoned_checkout

Checkout abandonado

Começou mas não concluiu. Seu backend dispara após o tempo limite.

Meta · evento personalizadoGA4 · abandoned_checkout
purchase

Compra realizada

Pagamento confirmado. A conversão que otimiza suas campanhas.

Meta · PurchaseGA4 · purchase

Precisa de outro evento? É só mandar outro event_name no webhook — o servidor aceita e você mapeia no painel.

Por que server-side

O navegador perde conversões. O servidor não.

Só pixel no navegador

  • Bloqueado por ad-blocker e extensões
  • Cortado pelo Safari (ITP) em 7 dias
  • Some se o cliente fecha a aba antes do envio
  • Depende de cookie de terceiro

Com o TrackServer

  • Passa: o tráfego é do seu próprio domínio
  • Cookie first-party sobrevive ao ITP
  • O servidor completa o envio de qualquer forma
  • Deduplica com o pixel pelo mesmo event_id

Tire suas conversões do navegador.

Cadastre um site, copie a URL de webhook e mande o primeiro evento em minutos.
